# Semantic Versioning & LTS Lifecycle // Nova WASM

`nova-wasm` adheres to Semantic Versioning 2.0.0 (`MAJOR.MINOR.PATCH`):
- **MAJOR:** Breaking changes to the core execution contract or type signatures.
- **MINOR:** Backward-compatible algorithmic optimizations or added hardware adapters.
- **PATCH:** Bug fixes, bounds verification enhancements, and documentation refinements.
